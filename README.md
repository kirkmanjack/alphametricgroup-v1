# Synaspe Markets — responsive HTML/Tailwind landing page

A responsive recreation inspired by the supplied screenshot, rebuilt as plain HTML + Tailwind CSS + a separate custom JavaScript file.

## Files
- `index.html` — complete page markup and Tailwind configuration
- `script.js` — mobile menu, smooth scrolling, reveal animations, active navigation, deal calculator, work with us, toast messages

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

Example:
```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes
- No React.
- No Next.js.
- Tailwind is loaded through the official CDN script in `index.html`.
